# Pokémon 維修等候頁

## 檔案
- `index.html`：網頁內容與結構（HTML）
- `style.css`：配色、排版、響應式設計與動畫（CSS）

## 在 GitHub Pages 發佈
1. 建立一個 GitHub repository。
2. 上傳 `index.html` 和 `style.css` 至 repository 根目錄。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` 分支與 `/(root)`，按 Save。
6. 等待部署完成後，開啟 GitHub Pages 提供的網址。

頁面中的品牌文字是以 CSS 仿製的文字標誌，像素角色以內嵌 SVG 繪製，沒有依賴外部圖片檔。Google Fonts 只是字型增強；若載入失敗，仍會使用系統字型。頁面不是 Pokémon 官方維修公告，僅作為課程／設計示範。
