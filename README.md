# Pokémon 維修等候頁

## 檔案
- `index.html`：網頁內容與結構（HTML）
- `style.css`：配色、排版、響應式設計與動畫（CSS）
- `Pokemon logo.png`、`pika.png`：頁面使用的圖片素材

## 在 GitHub Pages 發佈
1. 建立一個 GitHub repository。
2. 上傳專案中的所有檔案至 repository 根目錄，確保 HTML 和圖片素材都能正確載入。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` 分支與 `/(root)`，按 Save。
6. 等待部署完成後，開啟 GitHub Pages 提供的網址。

頁面使用 repository 中的 `Pokemon logo.png` 與 `pika.png` 圖片素材。Google Fonts 只是字型增強；若載入失敗，仍會使用系統字型。頁面不是 Pokémon 官方維修公告，僅作為課程／設計示範。
